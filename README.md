# Amazon Expedition 3D

A first-person jungle adventure game that runs entirely in your browser.
Explore a living Amazon rainforest, collect glowing gems, discover the lost
Temple of the Jaguar, and return the Golden Idol to your expedition boat.

![genre](https://img.shields.io/badge/genre-adventure-green) ![engine](https://img.shields.io/badge/engine-Three.js%20r128-blue)

## How to play

1. Keep `amazon_3d.html` and `three.min.js` in the same folder.
2. Double-click `amazon_3d.html` (opens in Chrome/Edge/Firefox).
3. Find the temple at the south end of the jungle, take the Golden Idol,
   and bring it back to the boat. Collect gems on the way for extra score.

## Controls

| Key | Action |
| --- | --- |
| W A S D | Move |
| Mouse | Look around |
| Shift | Sprint (uses energy) |
| Space | Jump |
| E | Pick up gems / idol |
| Esc | Pause |

## Features

- Procedural 3D jungle: hills, a great river, and ancient ruins
- Wildlife: circling birds, butterflies, hopping monkeys
- Energy system: sprinting and wading drain energy, resting restores it
- 10 hidden gems, a Golden Idol quest, score tracking, and a minimap
- Pointer-lock first-person controls with jump physics

## Requirements

- Any modern browser with WebGL
- `three.min.js` (Three.js r128) in the same folder
